# 🌱 Spring Study Repository

이 레포지토리는 **스프링 스터디 실습용 repository**입니다.  
각자 강의를 수강하며 실습한 내용을 정리하고, 학습 과정을 공유하기 위해 사용합니다.

---

## 🫧 1주차
- 프로젝트 생성 및 빌드
- 정적 컨텐츠, MVC(템플릿 엔진 활용), API
- Domain, Repository, Service 계층 개발
- 테스트 코드 작성 (`@AfterEach`, `@BeforeEach`)

- 회원 관리 예제로 웹 MVC 개발
- 스프링 DB 접근 기술 실습
> - 순수 JDBC

> - JPA
> - 스프링 데이터 JPA
